# Эксплуатация и диагностика IP / PORT Scanner — stable v0.4.0 / Windows Preview 0.5.0

## Перед первым запуском

1. Загрузите релиз с [GitHub Releases](https://github.com/uzbatsu-beep/IP_PORT/releases/tag/v0.4.0), проверьте ZIP по [SHA-256](PACKAGING.md), распакуйте в папку пользователя.
2. Проверьте права пользователя на открытие сетевых соединений и запись файлов отчётов. Для TCP-connect, обычного UDP и чтения локального neighbor-cache права администратора обычно не нужны.
3. Если это сегмент АСУ ТП/OT, заранее утвердите область сканирования и исключения; **не запускайте** активные пробы по контроллерам безопасности, PLC, роботам и критичному оборудованию без отдельного разрешения.
4. Оставьте сбор баннеров выключенным при первичной инвентаризации. PTR и MAC/OUI — опциональны, по умолчанию выключены.

## Типовые неполадки

| Симптом | Возможная причина | Действие |
|---|---|---|
| `Services database` неожиданно закрывает приложение | Дефект ранней версии или иной сбой Windows | Убедитесь, что используется проверяемый актуальный выпуск, выполните W-03 из [TESTING.md](TESTING.md), снимите Windows crash report |
| У хоста нет MAC | Хост за маршрутизатором, сосед отсутствует в ARP/NDP-кэше, либо запись неоднозначна | Уточните фактический соседний интерфейс, не трактуйте N/A как ошибку сети |
| `PTR no name` / `Resolver error` | Нет PTR, ошибки DNS или задержки системного резолвера | Проверьте DNS-политики, счётчики и последнюю ошибку; не принимайте soft warning за отмену |
| `PTR exceeded warning threshold` | Системный DNS-вызов выполняется дольше порога | Подождите завершения, при необходимости отключите PTR; жёсткая отмена вызова пока не поддерживается |
| Импорт IEEE CSV не завершается | Большой CSV, ошибка формата/прав, антивирус, повреждение диска | Проверьте ограничения 16 МиБ, столбцы CSV и локальный каталог OUI; старый валидный кэш должен сохраниться |
| После `Reset OUI` производитель всё ещё определён | Есть встроенный vendor map для данного MAC | Это нормально: `Reset` удаляет импортированные реестры, не встроенный список |
| UDP показывает `Open|Filtered` | Ответ/ICMP отсутствует или отфильтрован | Не считайте порт подтверждённо открытым; для неподтверждённого RTT используйте N/A |
| Время RTT кажется большим | TCP-connect/ответная датаграмма отражает сеть, таймаут и ОС; это не ICMP ping | Используйте сеть с известной задержкой и ограничивайте конкурентность (для UDP рекомендация ≤64) |

## Аварийное завершение на Windows

1. Нажмите `Win+R`, выполните `perfmon /rel` (**Монитор стабильности системы**).
2. Выберите событие в момент сбоя и запишите **Faulting application**, **Faulting module**, **Exception code** (если они показаны).
3. При необходимости откройте **Просмотр событий** → Журналы Windows → Приложение и найдите совпадающую по времени запись `Application Error`.
4. При `0xC00000FD` подозревайте переполнение стека; такой код **не доказывает** конкретную причину без стека вызовов. Ошибка процесса `msedgewebview2.exe` не обязательно относится к native egui-приложению IP_PORT.
5. Приложите к баг-репорту обезличенные сведения: версию и хэш файла, Windows build, шаги, код исключения, последнюю страницу интерфейса и ожидаемое действие. Не публикуйте пароли/схемы сети.

## Работа с конфигурациями и экспортом

- Профили JSON сохраняют цели, порты, протокол, сетевой bind-адрес, исключения, опции PTR/MAC и порог предупреждения PTR. Профиль не является доказательством того, что все цели безопасны — перед каждым запуском проверяйте scope.
- Результаты экспортируются в CSV/JSON/HTML на момент нажатия. HTML автономный, но может содержать сведения об адресах и службах; храните отчёты в соответствии с локальной политикой.
- Для диагностики больших сетей избегайте неограниченной конкурентности и активных проб по OT-сетям; сначала воспроизведите проблемы на лабораторной инфраструктуре.
