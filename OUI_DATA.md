# IEEE OUI — загрузка, хранение и диагностика

## Поддерживаемые наборы

IP_PORT v0.4.0 умеет загружать официальные CSV IEEE Registration Authority:

| Реестр | Размер назначения | Пример распространённого имени |
|---|---|---|
| MA-L | 24 бита | `oui.csv` |
| MA-M | 28 бит | `mam.csv` / `oui28.csv` |
| MA-S | 36 бит | `oui36.csv` |

**Источник CSV:** [IEEE Registration Authority](https://standards.ieee.org/products-programs/regauth/). Приложение **не скачивает** реестры автоматически; загрузите файлы вручную из доверенного источника. В каждом файле должны присутствовать колонки `Registry`, `Assignment`, `Organization Name`. Принимается корректный CSV с экранированием кавычек и запятых в именах, а также UTF-8. Не импортируйте неизвестные исполняемые файлы, ошибочно названные CSV.

## Алгоритм сопоставления

1. MAC должен быть корректным шестибайтовым уникаст-адресом с глобально назначенным префиксом; locally administered, multicast и некорректные адреса не получают надуманного производителя.
2. Если подходят несколько записей, используется **наиболее длинный префикс**: MA-S (36) → MA-M (28) → MA-L (24).
3. При отсутствии записи в импортированных файлах используется небольшая встроенная таблица производителей; неизвестный префикс остаётся неопределённым.
4. IP и MAC берутся только из локального системного **ARP/NDP-кэша**. Windows использует read-only `GetIpNetTable2`, Linux/macOS читают поддерживаемые системные таблицы/утилиты. MAC удалённых хостов обычно неизвестны.
5. Если один IPv6 link-local IP обнаружен на нескольких интерфейсах, IP_PORT **не выбирает случайный MAC**; интерфейсы перечисляются в сведениях о хосте. Полный ввод скан-цели `fe80::...%zone` ещё не реализован.

## Путь локального кэша

| ОС | Путь по умолчанию |
|---|---|
| Windows | `%LOCALAPPDATA%\IP_PORT\oui` (при отсутствии LOCALAPPDATA — `%APPDATA%`) |
| Linux | `$XDG_DATA_HOME/ip_port/oui` либо `~/.local/share/ip_port/oui` |
| macOS | `~/Library/Application Support/IP_PORT/oui` |

Сохраняются `ma-l.csv`, `ma-m.csv`, `ma-s.csv`. Временный файл `.new` и резервный `.bak` используются для замены данных с возможностью восстановления после прерывания. **Лимит** одного импортируемого CSV — 16 МиБ; неправильный CSV не заменяет предыдущий успешно сохранённый файл. Импорт выполняется в фоновом потоке, поэтому GUI остаётся отзывчивым.

`Reset OUI` сбрасывает импортированные записи и удаляет кэш пользователя. При проблемах с правами файловой системы интерфейс сообщает об ошибке; проверьте доступность каталога, антивирус и свободное пространство на диске.

## Область применимости и безопасность

IEEE OUI показывает организацию, которой выдан блок MAC-адресов. Это **не доказательство производителя, модели или подлинности конкретного устройства**: возможны переопределение MAC, виртуализация, смена сетевого модуля и устаревшие регистрационные данные. Не используйте OUI как единственный фактор для классификации критичного OT-оборудования.

Импортированные файлы содержат только общедоступную регистрационную информацию, не историю сканирования. Файлы локально сохраняются без криптографической подписи со стороны IP_PORT; убедитесь в происхождении данных. Отдельный сетевой запрос выполняется только если пользователь включает PTR-идентификацию. Дополнительные сценарии проверки: [TESTING.md](TESTING.md), эксплуатация — [OPERATIONS.md](OPERATIONS.md).
