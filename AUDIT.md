## Существующие технические риски — не выдавать за исправленные

| Приоритет | Ограничение | Предлагаемый отдельный этап |
|---|---|---|
| P1 | PTR использует блокирующий системный `lookup_addr`; мягкий порог измеряет превышение, но не прерывает вызов | Отдельный cancellable resolver, с контрольным тестом времени |
| P1 | Не проведены испытания на реальной OT-сети; active banner probes потенциально нежелательны для контроллеров | Отдельная лабораторная/производственная приёмка с разрешением владельца сети |
| P2 | IP link-local IPv6 ещё не может вводиться в scope с `%zone`; одинаковые IP по интерфейсам остаются неоднозначными | API таргетирования по interface ID и регрессионные тесты |
| P2 | Нет цифровой подписи Windows EXE, macOS notarization и provenance | Обсудить code signing и attestations |
| P2 | `src/app.rs` — крупный агрегатор UI состояния и фоновых задач | Поэтапная декомпозиция без изменения поведения, профильные тесты/benchmarks |
| P2 | Импортируемые IEEE CSV не проверяются криптографической подписью официального источника | Опциональная проверка подлинности/версии источника без автоматического онлайн-скачивания |
