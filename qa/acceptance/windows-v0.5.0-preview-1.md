## D-01 — старт

Загрузить ZIP и SHA256SUMS.txt с одной страницы релиза. PowerShell в папке загрузок:

```powershell
$zip = '.\\ip_port_scanner-preview-windows-v0.5.0-1-x86_64-pc-windows-msvc.zip'
$manifest = '.\\SHA256SUMS.txt'
$expected = '69bb6fa326070483e8543806383af9752674366d2c3d9ac860d25a2939ec36ee'
$actual = (Get-FileHash -LiteralPath $zip -Algorithm SHA256).Hash.ToLowerInvariant()
$actual
$actual -eq $expected
Get-Content -LiteralPath $manifest
```

Сопоставить имя ZIP и значение в манифесте с фактическим хэшем. При несовпадении не запускать. Если совпало, распаковать, открыть exe как обычный пользователь, записать фактическую версию (если не отображена — имя архива, commit из релиза), Windows build (winver), наличие/отсутствие ошибок запуска. Не обходить предупреждения ОС без проверки происхождения. D-01 PASS только при совпадении и успешном запуске.

## D-08 — UDP: контролируемая диагностика

Сначала не использовать промышленный сегмент. Настроить Custom, UDP, target 127.0.0.1, порт 49080, timeout 1000 ms, concurrency 1, source Auto либо 127.0.0.1, PTR/MAC off; не включать TCP banner grabbing как доказательство UDP. Если порт занят, выбрать свободный высокий порт и одинаково изменить настройки. В текущей реализации специализированные датаграммы только 53/DNS, 123/NTP, 161/SNMP, 137/NetBIOS; остальные — один нулевой байт. Поэтому отсутствие ответа промышленного UDP-сервиса не доказывает его отсутствие.

**A — отвечающий сокет.** В отдельном окне Windows PowerShell запустить временный loopback listener, не открывая внешний интерфейс:

```powershell
$u = [System.Net.Sockets.UdpClient]::new([System.Net.IPEndPoint]::new([System.Net.IPAddress]::Loopback,49080))
try {
  while ($true) {
    $peer = [System.Net.IPEndPoint]::new([System.Net.IPAddress]::Any,0)
    $data = $u.Receive([ref]$peer)
    Write-Host "Received $($data.Length) bytes"
    [void]$u.Send($data,$data.Length,$peer)
  }
} finally { $u.Dispose() }
```

Сканировать только 127.0.0.1:49080. Ожидается Open, RTT измерен; записать счётчики и поле Evidence. Это UDP echo, **не** доказательство конкретного протокола. Текущий service_verified устанавливается по ответу, что проверяем как TD-09.

**B — молчащий сокет.** Остановить A (Ctrl+C; закрыть окно при необходимости), повторно запустить тот же listener, удалив строку Send. Ожидается принятая датаграмма в PowerShell, Open|Filtered в IP_PORT, RTT не измерен; отсутствие ответа не равно Closed.

**C — закрытый порт.** Закрыть listener, убедиться, что порт не занят (`Get-NetUDPEndpoint -LocalPort 49080 -ErrorAction SilentlyContinue`). Повторить. Если Windows сообщает ICMP Port Unreachable/WSAECONNRESET — Refused в счётчиках, открытая строка отсутствует. Если ICMP не доставлен, Open|Filtered допустим; зафиксировать наблюдение, не объявлять FAIL только по таймауту. При необходимости отдельно проверить локальный capture на разрешённом стенде. Не отключать firewall глобально.

**D — разрешённый известный сервис.** После A–C выбрать один доступный UDP сервис и согласовать его штатный безопасный запрос, ожидаемый ответ и таймаут. Сравнить с текущим payload; фиксировать протокол, приложение/сервис и состояние, не утверждать протокольную идентификацию по любому ответу. Отдельно проверить счётчики Open / Open|Filtered / Refused / Errors, отображение RTT и экспорт.
