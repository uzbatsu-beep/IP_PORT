# IP / PORT Scanner

Кроссплатформенное приложение для сканирования IP-адресов и TCP-портов с современным интерфейсом на Rust.

![Rust](https://img.shields.io/badge/Rust-1.95%2B-orange)
![egui](https://img.shields.io/badge/GUI-egui%200.37-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## Возможности

- Сканирование IPv4/IPv6-адресов и CIDR-подсетей, а также диапазонов IPv4
- Гибкий выбор портов: диапазоны (`1-1024`), списки (`22,80,443`), сервисные пресеты
- Асинхронный движок на Tokio: сотни параллельных подключений с ограничением конкурентности
- Настраиваемые таймауты подключения и количество воркеров
- Живой вывод открытых портов, времени TCP-соединения и предполагаемого сервиса по номеру порта
- Прогресс сканирования, статистика, отмена в любой момент
- Фильтрация по адресу, порту или сервису, сортировка по всем столбцам и контекстные действия для результатов
- Экспорт результатов в CSV / JSON
- Современная тёмная тема и адаптивный layout

## Стек

| Компонент | Технология |
|-----------|------------|
| Язык | Rust 2024 edition |
| GUI | `eframe` + `egui` (нативный рендеринг через `glow`) |
| Асинхронность | `tokio` (multi-thread runtime) |
| Парсинг сетей | `ipnet` |
| Диалоги файлов | `rfd` |
| Отмена задач | `tokio-util` (`CancellationToken`) |

## Архитектура

```
src/
├── main.rs          # точка входа, инициализация eframe
├── app.rs           # состояние UI и обработка событий
├── ui/
│   ├── mod.rs       # регистрация панелей интерфейса
│   ├── sidebar.rs   # форма целей, портов и настроек
│   ├── results.rs   # таблица открытых портов
│   └── theme.rs     # современное тёмное оформление
├── scanner/
│   ├── mod.rs       # запуск и управление сканированием
│   ├── targets.rs   # разбор целей: IP, CIDR, диапазоны портов
│   └── probe.rs     # TCP-connect проверка с таймаутом
└── export.rs        # сохранение результатов в CSV / JSON
```

Сканирование выполняется в отдельном Tokio-рантайме. События передаются в UI через канал
`mpsc`, а `CancellationToken` используется для остановки текущей сессии. Подробнее о текущем
устройстве и ограничениях — в [архитектуре](ARCHITECTURE.md).

## Сборка и запуск

```bash
# отладочная сборка
cargo run

# релизная сборка
cargo build --release

# тесты
cargo test
```

На Linux могут потребоваться системные зависимости для `winit`/`glow`:

```bash
sudo apt install libxkbcommon-dev libwayland-dev libgl1-mesa-dev
```

## Использование

1. Введите цели в поле **Targets** — по одной на строку: IP, CIDR или диапазон IPv4, например `10.0.0.1-10.0.0.20`. Строки, начинающиеся с `#`, игнорируются. Поддерживаются и IPv6-адреса, например `::1`.
2. Укажите порты: `22,80,443`, `1-1024` или выберите пресет (**Common**, **Web**, **Database**).
3. Настройте таймаут и конкурентность при необходимости.
4. Нажмите **Start scan** или используйте **Ctrl+Enter** (на macOS — **Cmd+Enter**). Открытые порты появляются в таблице по мере обнаружения. Доступна полная клавиатурная навигация: стрелки **Up / Down**, **Home**, **End** для перемещения по строкам, **Enter / Space** для открытия web-портов в браузере или копирования, **Filter** (хоткей **Ctrl/Cmd+F**), заголовки столбцов для сортировки и контекстное меню по правому клику (с автоматическим выделением строки) для копирования адресов/результатов.
5. **Stop** запрашивает отмену. **Clear** удаляет уже собранные результаты, но не останавливает сканирование — новые результаты продолжат поступать. Меню **Export ▾** сохраняет CSV или JSON с timestamp-именем по умолчанию (`scan_results_YYYYMMDD_HHMMSS.{ext}`) и формирует кликабельную ссылку для перехода к файлу в проводнике.

Сейчас приложение выполняет только TCP-connect-проверки: неудачные попытки не выводятся,
а название сервиса предполагается по номеру порта, без проверки баннера. Имена хостов не
разрешаются. Лимит — 65 536 уникальных адресов на запуск; IPv4 CIDR ограничен `/16` и уже,
IPv6 CIDR — `/120` и уже. Диапазоны адресов поддерживаются только для IPv4.
