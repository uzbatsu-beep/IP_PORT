## [0.3.1] — 2026-11-20

### Исправлено
- Восстановлена сборка macOS Intel в релизном workflow: `macos-13` заменён на поддерживаемый `macos-15-intel`; публикация релиза выполняется только по тегу после успешных сборок всех платформ.
- Исправлена статистика времени отклика UDP: состояния `Open|Filtered` не содержат подтверждённого RTT и исключены из гистограммы и агрегатов.
- Таблица результатов отображает отсутствие RTT для `Open|Filtered` символом `—`. Экспорт: CSV — пустое поле `rtt_ms`, JSON — `null`, HTML — `N/A`; без ошибочного приравнивания таймаута к задержке.
- Устранена квадратичная сложность группировки результатов по IP благодаря индексации хостов через `HashMap`.
- Статистика RTT кэшируется до изменения набора результатов вместо пересортировки при каждом кадре интерфейса; сводка хоста показывает N/A, когда подтверждённых ответов нет.
- Отмена сканирования прерывает выполняющийся асинхронный DNS-запрос немедленно через `tokio::select!`.
- Добавлены регрессионные тесты для UDP RTT, семантики экспорта, группировки хостов и кэша статистики.

### Совместимость
- В JSON/CSV схеме v1 при `Open|Filtered` поле `rtt_ms` теперь обозначает отсутствие измерения; для подтверждённых `Open` числовой формат не изменён. Потребителям данных следует учитывать `null` и пустое CSV-поле.

## [0.3.0] — 2026-11-18

### Добавлено
- **Автоматическое извлечение названий веб-страниц (HTTP Title Grabbing):**
  - Поддержка извлечения тегов `<title>...</title>` во время сбора баннеров для HTTP- и HTTPS-служб (включая страницы 400 Bad Request на портах SSL).
  - Полнофункциональный декодер именованных (`&amp;`, `&quot;`, `&lt;`, `&gt;`, `&copy;`, `&mdash;`...) и числовых (`&#8212;`, `&#x2014;`) HTML-сущностей (`decode_html_entities`).
  - Устойчивый парсер `<title>` с поддержкой любых атрибутов (`<title lang="...">`), нечувствительностью к регистру, нормализацией пробельных символов и безопасной обработкой усечённых сетевых потоков.
  - Форматирование баннера в структурированный вид: `HTTP/1.1 <status> Server: <server> [Title: <title>]` или `HTTP/1.1 <status> [Title: <title>]`.
  - Автоматическая верификация сервиса (`service_verified = true`, `confirmed_service = "http"`, значок `✔`) при обнаружении веб-заголовков или тегов HTML.
  - Увеличение буфера чтения баннеров с 256 байт до 2048 байт с дочитыванием тела ответа при обнаружении HTTP-заголовков.
- **Экспорт в автономный интерактивный HTML-отчёт (`export::save_html`):**
  - Генерация полностью автономного однофайлового HTML-документа без внешних зависимостей (CDN, шрифты, внешние скрипты) — открывается офлайн в любом современном браузере.
  - Современный тёмный UI-дизайн с информативными карточками метрик: общее число открытых портов, число уникальных хостов, разделение по TCP/UDP, минимальная, средняя и максимальная задержка RTT.
  - Мгновенный клиентский поиск и фильтрация по тексту (хост, порт, сервис, баннер), а также быстрые фильтры по протоколам (`All`, `TCP`, `UDP`).
  - Интерактивная сортировка колонок таблицы результатов по клику на заголовки.
  - Безопасное экранирование всех баннеров и текстовых полей от XSS (`escape_html`).
  - Опция экспорта `Export HTML report... (*.html)` в выпадающем меню панели действий.
- **Древовидная группировка результатов по хостам (`Group by Host`):**
  - Переключатель режимов отображения в панели фильтра (`☰ Flat` / `🗂 By Host`).
  - Автоматическая группировка найденных портов по уникальным IP-адресам со сводными метриками хоста (количество портов, перечень сервисов, минимальный RTT).
  - Сворачиваемые заголовки хостов (`CollapsingHeader`) с кнопками быстрых действий (`Copy IP`, `Filter`, `Scan Host`).
  - Сохранение полной функциональности контекстных действий и нижней панели-инспектора для каждого порта внутри хоста.
  - Высокоэффективное O(N) кэширование групп без повторной сборки на холостых кадрах отрисовки.

## [0.2.0] — 2026-11-18

### Добавлено
- **Контекстные быстрые действия и инспектор строки (`ui::quick_actions`):**
  - Обогащенное контекстное меню по правому клику мыши на строку:
    - Открытие веб-портов (HTTP/HTTPS) в системном браузере в 1 клик (`Enter` или контекстное меню).
    - Копирование готовых команд: `curl -vk ...`, `ssh ... -p ...`, CLI для СУБД (`mysql`, `psql`, `redis-cli`).
    - Копирование адреса (`IP:Port`, `IP`, `Port`), баннера, строки (TSV) или компактного JSON-объекта в буфер обмена.
    - Быстрая фильтрация таблицы по выбранному IP-адресу (`Filter by this IP`).
    - Немедленная подстановка хоста в поле целей сканера с диапазоном портов `1-1024` для глубокого анализа (`Set as scan target`).
  - Нижняя панель-инспектор быстрых действий (Inspector Toolbar) при выделении строки, предоставляющая быстрый доступ ко всем операциям без необходимости правого клика.
- **Интерактивная визуализация и статистика задержки RTT (`ui::rtt_view`):**
  - Автоматический расчёт ключевых метрик задержки отклика для найденных открытых портов: минимум, среднее, медиана, 95-й процентиль (p95) и максимум.
  - Адаптивные корзины распределения: автоматическая калибровка диапазонов задержки в зависимости от масштаба времени отклика (субмиллисекундный localhost/loopback, гигабитный LAN, городская сеть или глобальный Интернет).
  - Сворачиваемая панель над таблицей результатов с компактной сводкой метрик в заголовке.
  - Горизонтальный составной прогресс-бар пропорций задержек и 5-колоночная столбчатая гистограмма с цветовой кодировкой (от изумрудно-зелёного до кораллово-красного).
  - Информативные всплывающие подсказки (tooltips) при наведении на столбцы с указанием точного диапазона, количества портов и процентной доли.
- **Выбор сетевого интерфейса и привязка к локальному IP (Network Interface Binding):**
  - Кроссплатформенное обнаружение локальных интерфейсов (Ethernet, Wi-Fi, VPN, WireGuard, Tailscale, loopback) без повышения привилегий через `get_if_addrs`.
  - Привязка исходящих TCP-соединений (`tokio::net::TcpSocket::bind`) и UDP-датаграмм (`tokio::net::UdpSocket::bind`) к выбранному локальному IP-адресу.
  - Интерактивный выпадающий список интерфейсов (`ComboBox`) в боковой панели UI с отображением имени и IP-адреса, кнопкой быстрого обновления `🔄` и текстовым полем для ручного ввода IP.
  - Валидация IP-адреса на лету в `InputCache` с отображением ошибок в превью и блокировкой старта сканирования при невалидном синтаксисе.
  - Сохранение и загрузка привязки сетевого интерфейса (`bind_addr`) в JSON-профилях (`ScanProfile`).
- **Модульная система пресетов портов с разделением по протоколам (`scanner::presets`):**
  - Быстрые наборы портов для TCP: `Common` (20 портов), `Top 100` (Nmap Top-100), `Web` (80, 443, 3000, 5000, 8080...), `Database` (MySQL, Postgres, MSSQL, Redis...), `Remote` (SSH, RDP, VNC...) и `1-1024` (системные).
  - Быстрые наборы портов для UDP: `Common UDP` (15 ключевых служб), `Top 20 UDP`, `VPN / Infra` (WireGuard, OpenVPN, IKE, L2TP) и `Discovery` (mDNS, SSDP, NetBIOS, DHCP).
  - Поддержка двух режимов применения: одиночный клик заменяет поле ввода портов, а клик с `Ctrl` или `Shift` объединяет порты без дублирования.
  - Алгоритм автоматического сжатия непрерывных последовательностей портов в диапазоны (`format_ports`).

## [0.1.0] — 2026-11-17

### Добавлено

#### Сетевой движок (TCP & UDP)
- **Асинхронный масштабируемый движок на Tokio:**
  - Генерация заданий по требованию (on-demand) без аллокации всех комбинаций адрес/порт в памяти.
  - Настраиваемая параллельность (1–1024 воркеров) и таймауты подключения (50–5000 мс).
  - Поддержка немедленной отмены через `CancellationToken` без зависания активных соединений.
- **Поддержка сетевых протоколов:**
  - Сканирование TCP Connect с измерением точного RTT подключения.
  - Сканирование UDP со специализированными RFC-пробами для популярных служб:
    - DNS (порт 53): валидный A-query (RFC 1035).
    - NTP (порт 123): клиентский запрос NTPv4 (RFC 5905).
    - SNMP (порт 161): SNMPv1 GetRequest (RFC 1157).
    - NetBIOS (порт 137): Node Status Request (RFC 1002).
    - Универсальный однобайтовый fallback `b"\0"`.
  - Трёхпозиционная модель классификации результатов UDP:
    - `Open`: получен явный датаграмм-ответ.
    - `Open|Filtered`: таймаут без ответа и без ICMP (неоднозначный исход по RFC 768 / RFC 1812).
    - `Closed` (`Refused`): асинхронный перехват ICMP Port Unreachable через подключенный UDP-сокет (`WSAECONNRESET` на Windows, `ECONNREFUSED` на Linux/macOS).
  - Адаптивный контроль параллельности для UDP ($\le 64$) из-за ограничения частоты ICMP ядрами ОС.
- **Адресация и цели:**
  - Одиночные IPv4 и IPv6 (`127.0.0.1`, `::1`).
  - CIDR-подсети (IPv4 до `/16`, IPv6 до `/120`, до 256 хостов).
  - Диапазоны адресов IPv4 (`start-end`) и IPv6 (`start_v6-end_v6` до 65 536 адресов).
  - Явная диагностика несовместимости с zone identifiers IPv6 (`%zone`).
  - Поддержка DNS-имён хостов (FQDN, `localhost`, `router.local`, `scanme.nmap.org`):
    - Синтаксическая валидация по RFC 1123 / RFC 952 в UI без сетевых обращений.
    - Асинхронное Dual-Stack разрешение A и AAAA записей перед стартом воркеров.
    - Дедупликация и защита от превышения лимита 65 536 адресов на запуск.
- **Определение сервисов и захват баннеров (Banner Grabbing):**
  - База соответствия портов `ServicesDb` со сложностью O(1) и поддержкой форматов `nmap-services`, `/etc/services` и IANA CSV.
  - Опциональный захват приветственных баннеров (SSH, FTP, SMTP, VNC, POP3, IMAP) и probe-баннеров (HTTP HEAD) с отдельным таймаутом (100–5000 мс), строгим ограничением буфера (256 байт) и визуальной отметкой подтверждения (`✔`).

#### Графический интерфейс (GUI)
- Современный тёмный интерфейс на `eframe` / `egui` с нативным ускорением через `glow`.
- Таблица результатов без визуального шума вертикальных разделителей колонок.
- Полная клавиатурная навигация: стрелки Up/Down, Home, End, Enter/Space (открытие веб-портов или копирование), Ctrl/Cmd+Enter (старт), Escape (стоп), Ctrl/Cmd+F (фокус фильтра), Ctrl/Cmd+C (копирование).
- Контекстное меню по правому клику с автоматическим выделением строки.
- Всплывающие toast-уведомления с таймером и анимацией fade-out.
- Сводные агрегированные счётчики закрытых портов, таймаутов, `Open|Filtered` и сетевых ошибок без расхода памяти на каждую неудачную пробу.
- Лимит хранения открытых результатов — 100 000 строк.

#### Данные, экспорт и профили
- Сохранение и загрузка версионируемых JSON-профилей настроек (схема v1) с атомарным откатом при ошибках валидации.
- Асинхронный экспорт снимка данных в CSV и JSON (схема v1) в отдельном системном потоке с потоковым экранированием по RFC 4180 и RFC 8259.
- Кликабельный путь сохранения экспорта с генерацией timestamp-имён по умолчанию (`scan_results_YYYYMMDD_HHMMSS.{ext}`).

#### Инфраструктура и качество
- 71 автоматический модульный и интеграционный тест, покрывающий сетевые операции, отмену, ошибки, GUI-состояние и нагрузочные сценарии (136 FPS на 20 000 результатов).
- Автоматический CI/CD пайплайн в GitHub Actions для Windows, Linux и macOS с проверками форматирования (`cargo fmt --check`), линтинга (`cargo clippy --all-targets -- -D warnings`), тестов и MSRV (Rust 1.95.0).
- Автоматизированная матричная сборка релизных пакетов и публикация на GitHub Releases с контрольными суммами SHA256.
